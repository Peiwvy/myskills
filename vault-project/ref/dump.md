# dump（更新进展）

触发：「dump 一下」「保存进度」「记录一下」。

## 步骤

1. 回顾本轮对话，确认哪个 `inprogress-*.md` 被涉及
2. 更新对应文件：

```markdown
# inprogress-A

- 来源：INBOX 梳理区 #A
- 目标：...
- 计划：...
- 问题：...（本轮新发现的问题）
- 决策：...（为什么选 A 不选 B——本轮做的关键取舍）
- 检验：...
```

3. 本轮做了多个 inprogress → 逐一更新

## 规则

- **只更新进展和决策，不写流水账**
- 决策有则写，没有就省略
- 没有活跃 inprogress → 「当前没有进行中的任务，先看 INBOX？」
- 发现新想法 → 追加到 `_cockpit/INBOX.md` 随想区（不要混进 inprogress）
- AI 自动更新，人审阅
