# design（处理 INBOX）

触发：「处理 INBOX」「看看随想」。

## 步骤

1. 读 `_cockpit/INBOX.md`
2. 如果随想区空 → 「随想区是空的」
3. 对随想区每条想法，做两件事：

### 归类 + 编号

- 同类想法合并成一条
- 给每条分配编号（A, B, C...）
- 写成一句清晰的「要做什么」
- 移到梳理区

### 升格判据

处理过程中发现跨 scope 的想法 → 标注 `[→父级]`，升格到父级 `_cockpit/INBOX.md` 梳理区。

## 梳理区格式

```markdown
## 梳理区

- A. 一句话说清要做什么
- B. 另一条
- C. [→项目级] 这条影响范围超出当前 scope
```

## 原则

- AI 归类 + 编号，人审阅
- 随想区条目处理后不移除——等对应 inprogress 完成时才删梳理区条目
- 编号按字母序（A-Z），用完可以循环
- 跨 scope 的升格到父级，标注来源
