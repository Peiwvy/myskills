# 华尔街见闻 (wallstreetcn)

华尔街见闻没有专属 opencli 适配器，使用通用 `opencli web` 适配器进行浏览器自动化抓取。

## 站点特点

- 文章索引页和正文均为服务端渲染，`opencli web read` 可直接抓取
- 无需登录即可访问大部分公开文章
- 索引页包含完整文章链接列表，适合批量爬取

## 抓取方式

### 索引页 → 提取文章链接

```bash
opencli web read --url "<专栏/课程索引页URL>" --format md
```

从输出找到保存路径，Read 读取索引页 markdown，提取所有文章链接（去重），记录标题和发布日期。按发布日期排序编号（最早 → 01）。

### 逐篇抓取文章正文

```bash
cd <用户指定的保存目录> && opencli web read --url "<文章URL>" --format md 2>&1 | tail -1
```

每次 5 篇串行抓取（opencli 每次调用会打开浏览器，不宜并发太多）。

### 文件归拢

全部抓取完成后，将文章归拢到统一目录，编号命名：

```
<保存目录>/<专栏名>-文章/
├── 01_文章标题.md
├── 02_文章标题.md
└── ...
```

### 保存路径确认（必须）

**每次抓取前必须先询问用户保存路径**。如果用户没有指定，默认保存到当前 IDE 打开的工作路径

### 图片处理

**不要保留图片**。抓取完成后删除 `images/` 目录，只保留 `.md` 文件。

## 常见问题

| 问题 | 处理 |
|------|------|
| 抓取失败 | 检查 URL 是否正确，确认页面是否被删除或设为私密 |
| 索引页无链接 | 可能是 JS 动态加载的列表页，尝试 `opencli browser` 手动操作 |
| 抓取内容含大量 UI 代码 | 华尔街见闻页面含视频播放器等 UI 组件，正文在 UI 代码之后，正常现象 |
| 文件名含特殊字符 | 用 `find` + 通配符定位文件，Bash `cat` 写入时避免引号嵌套 |
