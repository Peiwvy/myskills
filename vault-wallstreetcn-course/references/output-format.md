# 华尔街见闻课程输出格式

每章输出**两个配对文件**：原文 + AI 总结。

---

## 文件 A：原始文章

**路径**：`K10-Source/Media/华尔街见闻/<课程名>/<编号> <标题>  <讲师名>·大师课.md`

注意：标题与讲师名之间是**双空格**。

**Frontmatter**：

```yaml
---
title: "<编号> <标题> | <讲师名>·大师课"
source: "<文章原始URL>"
author:
  - "[[<讲师名>·大师课]]"
published: <YYYY-MM-DD>
created: <YYYY-MM-DD>
description: "<一句话提要>"
tags: [state/source/sorted]
---
```

**正文**：逐字稿原文，保留 `##` 层级标题和图片 URL。不做删减或改写。

---

## 文件 B：AI 结构化总结

**路径**：`K10-Source/Media/华尔街见闻/<课程名>/<编号> <标题>-总结.md`

**Frontmatter**：

```yaml
---
title: <讲师名>-<短标题>-总结
tags: [state/source/sorted]
date: <YYYY-MM-DD>
up:
  - "[[<原文文件名（不含路径）>]]"
---
```

**正文模板**：

```markdown
> [!abstract] 全文思路
> 一句话概括全文核心逻辑链（因果关系、论证路径）

---

## 一、<第一个核心论点>

> [!quote]
> 原文关键语句引用

展开论述。==最重要的洞察用高亮包裹==。

| 维度A | 维度B |
|------|------|
| ... | ... |

---

## 二、<第二个核心论点>

...（同上模式，根据内容灵活分 2-5 节）

---

> [!abstract]
> 收尾总结全篇，点明最核心的 takeaway。
```

**格式规范**：

| 元素 | 用法 |
|------|------|
| `[!quote]` | 引用原文关键句 |
| `[!important]` | 核心信条、铁律 |
| `[!warning]` | 风险警示、反面案例 |
| `[!tip]` | 实操建议 |
| `[!example]` | 生动案例、比喻 |
| `[!abstract]` | 全文总结（开头可用"全文思路"，结尾用总结） |
| `==高亮==` | 全篇最重要的1-3个洞察 |
| 表格 | 对比多个维度时使用 |
| 图片 URL | 保留原文中的关键图表，不要删除 |

**AI 撰写原则**：

1. **提炼而非缩写**——删除口语化冗余，保留逻辑链和因果机理
2. **保留硬数据**——具体时间、数字、百分比不能丢
3. **保留生动比喻**——如"钱就是君王""仓库粮食""熬不过冬天"等
4. **保留反直觉观点**——用 `==高亮==` 标记
5. **每节有引用**——至少一条 `[!quote]` 锚定原文
6. **结论先行**——每节开头先给结论，再展开

## 特殊文件

### 课程入口文件

**路径**：`K10-Source/Media/华尔街见闻/<课程名>/<课程名>.md`

**内容**：仅 frontmatter，不含正文。

```yaml
---
tags: [state/source/sorted]
links:
sorted:
title: <课程名>
date created: <YYYY-MM-DDTHH:mm>
date modified: <YYYY-MM-DDTHH:mm>
url: <专栏索引页URL>
---
```

### 课程总览总结

**路径**：`K10-Source/Media/华尔街见闻/<课程名>/0.0 <课程名>课程总览-总结.md`

对专栏索引页本身的结构化总结，格式同文件 B。包含课程元信息（讲师、平台、章节数）和课程结构概览。

### 对话录 / 番外

如果课程中包含对话录或番外内容，编号用 `0.1`、`0.2` 等。
