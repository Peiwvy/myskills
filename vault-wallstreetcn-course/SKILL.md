# 华尔街见闻课程导入

将华尔街见闻专栏页面批量抓取，每章输出原文 + AI 结构化总结的配对文件，存入 `K10-Source/Media/华尔街见闻/<课程名>/`。

## 架构概览

```
索引页抓取 → 建目录 → 串行抓取全部原文 → 并行 Agent 总结 → 清理
                    (opencli 限制)       (vault-summarize × N)
```

- **抓取阶段串行**：opencli 共用浏览器实例，并发会导致冲突
- **总结阶段并行**：原文落盘后，每篇启动一个 Agent 调用 `vault-summarize` 并行生成总结

## 工作流

### 阶段 1：抓取索引页

```bash
opencli web read --url "<专栏URL>" --format md
```

Read 抓取结果，提取：

- 课程名称（页面标题）
- 讲师名称（作者字段）
- 所有文章链接和标题，按发布日期**升序**排列（最早发布 → 编号 01）

### 阶段 2：创建目录结构

在 `K10-Source/Media/华尔街见闻/` 下创建课程子目录，写入两个文件：

1. **课程入口文件** `<课程名>.md` — 仅 frontmatter，记录来源 URL
2. **课程总览** `0.0 <课程名>课程总览-总结.md` — 调用 `vault-summarize` 对索引页本身做结构化总结（课程元信息、章节结构、逻辑递进）

格式模板见 [output-format.md](references/output-format.md)。

### 阶段 3：串行抓取全部原文

按编号顺序逐篇抓取，每次 5 篇一批（opencli 每次打开浏览器，不宜并发）。

每篇执行：

```bash
cd "<课程目录>" && opencli web read --url "<文章URL>" --format md
```

将抓取结果另存为原文文件，命名 `<编号> <标题>  <讲师名>·大师课.md`（标题与讲师名之间**双空格**），补全 frontmatter，删除 `images/` 目录。

全部抓取完成后，Glob 确认原文文件清单。

### 阶段 4：并行 Agent 总结

原文全部落盘后，用 **parallel Agent** 并行处理总结。每个 Agent 负责一篇原文：

```
Agent N: 读取 <原文文件> → 调用 vault-summarize → 写入 <-总结.md>
```

每个 Agent 的 prompt 模板：

```
读取 <原文文件路径>，调用 vault-summarize 将其整理为结构化笔记。
输出文件命名为 <编号> <标题>-总结.md，格式严格遵循 references/output-format.md。
要求：提炼核心论点、保留硬数据和生动比喻、使用 callout 和表格、==高亮==关键洞察、以 [!abstract] 收尾。
```

**并行度**：全部文章同时启动 Agent，由系统自动调度。

### 阶段 5：收尾

1. 如有对话录/番外，编号用 `0.1`、`0.2`，同样生成原文+总结配对
2. 删除 opencli 生成的 `web-articles/` 子目录
3. 输出完成报告：列出已生成的全部文件、标注失败的章节（如有）

## 关键约束

- **抓取串行，总结并行**——这是由 opencli 浏览器架构决定的硬约束
- **总结走 vault-summarize**——不要自己直接写总结，统一走 skill 确保格式一致
- **先确认再覆盖**——如果目标目录已存在同名文件，询问用户
- **图片不保留到本地**——原文中保留图片 URL 即可，opencli 下载的 `images/` 目录删除
- **日期来源**——`published` 用页面显示的发布日期，`created` 用当天日期
- **编号对齐**——按发布日期升序编号，最早的文章为 01（索引页通常是倒序的）

## 常见问题

| 问题 | 处理 |
|------|------|
| 抓取失败 | 重试一次，仍失败则跳过，在完成报告中标注 |
| 文章含视频无文字 | 标注"视频内容，无逐字稿"，只生成简化总结 |
| 索引页无链接（JS 渲染） | 尝试 `opencli browser` 手动操作 |
| 文件名含特殊字符 | 用 `find` + 通配符定位，Bash 操作时避免引号嵌套 |
